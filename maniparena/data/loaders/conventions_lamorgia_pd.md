Notes
- Timezone: the README states "hour: the pump and dump hour expressed in UTC"; `date` is read as the UTC date. Checked on the clone of 2026-10-03: all 317 officially labelled start chunks lie within 180 s of a UTC announcement of the same coin.
- Repository state on 2026-10-03: 1,110 rows (2017-07-05 … 2021-01-18), 520 Binance rows, 320 Binance events after merging; the official feature files hold 317 pumps. These differ from the 1,485 events / 2021-01-15 end date quoted in the build spec.
- The authors' trades came from the Binance REST API (ccxt); we read the same trades from Binance Vision daily files. Pairs that Binance Vision no longer serves cannot be loaded.
- Label caveat: the authors' manual start can precede the announcement by up to 120 s (README); our t0 is the announcement, as specified.
- Choices not fixed by the spec: announcements of one pair within 60 s (`merge_tol_s`) are one event with `meta["groups"]`; quote currency BTC; neighbouring pumps labelled; frames whose trades do not reach the announcement are rejected; bar grid anchored at the first trade in the window (a property of `trades_to_barframe`).
